# Banking Roadmap

## Deferred

- User-configurable daily debit/credit summary notification.
- Exact-alarm evaluation only if the future notification must arrive at an exact user-selected time.
- Broader verified balance-service coverage for registry entries currently marked `NONE`.
- Bank-logo redistribution review and generic-logo fallback decisions before public release.

The daily summary must remain local-only, must not expose sensitive values on the lock screen,
and must not be implemented by reusing realtime NER foreground execution.
